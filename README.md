Librairie virtuelle - Projet Python

Ce projet est une application Python simple permettant de gérer une bibliothèque virtuelle depuis le terminal.
L’utilisateur peut ajouter, modifier, supprimer et afficher des livres, grâce à un menu interactif et ergonomique.

 Description du projet

Cette application fonctionne en ligne de commande et permet de gérer une liste de livres stockés dans une variable Python.
Le programme utilise une boucle principale pour afficher un menu et exécuter différentes actions selon le choix de l’utilisateur.

L’objectif du projet était d’apprendre :

la gestion des listes en Python

l’utilisation de conditions et de boucles

la construction d’un menu interactif

la gestion d’entrées utilisateurs

la mise à jour dynamique de données

Au fil de l’évolution du script, plusieurs améliorations ont été apportées :

Affichage propre de la liste des livres (sans crochets ni apostrophes)

Pause après chaque action pour éviter un retour instantané au menu

Messages de confirmation plus clairs

Numérotation automatique lors de l'affichage des livres

Fonctionnalités

Lister les livres : affiche proprement chaque livre avec une numérotation.

Ajouter un livre : ajoute un nouveau titre à la bibliothèque.

Modifier un livre : remplace un ancien titre par un nouveau.

Supprimer un livre : retire un titre existant de la liste.
